# สถานะล่าสุด (บันทึก 2026-11-12) — Phase 2a เสร็จ · รอเตือนเรื่องค้างหลังปิดเรื่องที่เช็ค

## ทำเสร็จแล้ว
**ใส่ภาพลงหน้าเว็บ**
- หน้าแรก: โลโก้จริงกับน้องจี๊ดถือจอยเกม สติกเกอร์ลอยรอบๆ และภาพประจำทั้ง 2 โซนบนการ์ด
- หน้าวงล้อ: น้องจี๊ดเปลี่ยนท่าตามจังหวะ (หมุน → กัดเล็บลุ้น → ชูถ้วย)
- หน้า 404 และหน้าที่ยังไม่เสร็จใช้ท่าที่ตรงกับเนื้อหา · ไอคอนและภาพแชร์ลิงก์ใช้งานแล้ว
- ข้อความใช้ตัวเลือก ① จาก `docs/copy.md`

**เว็บโหวต (Phase 2a — ระบบจำลอง: ข้อมูลเก็บในเบราว์เซอร์, login Slack แบบเลือกชื่อเอง)**
- `/vote` มือถือ: สมัครประกวด + แนบรูป (ย่ออัตโนมัติ) · เห็นสิทธิ์ +10/+1 และเวลาที่เหลือ · เลือก → ยืนยัน → บัตรลงคะแนน
- `/vote/admin` 4 แท็บ: ภาพรวม · ผู้ประกวด · ผู้ใช้และสิทธิ์ · งานทั้งหมด
- `/vote/stage`: ระหว่างโหวตโชว์จำนวนคน + เวลา (ไม่โชว์คะแนน) · เปิดผลทีละอันดับจากท้าย (Space/รีโมต) · อันดับ 1 มีพลุ · หมดเวลาปิดเอง
- ทดสอบอัตโนมัติ 4 แท็บพร้อมกันผ่านทุกข้อ (ยังไม่ได้ลองบนมือถือ/โปรเจกเตอร์จริง)
