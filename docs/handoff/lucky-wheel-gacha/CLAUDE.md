# Matchazuki Lucky Day (วงล้อคู่ + ตู้กาชาปอง)

อ่าน `SPEC.md` ก่อนเริ่มงานทุกครั้ง — มีทั้ง requirement, สิ่งที่ผู้ใช้ปฏิเสธไปแล้ว (ห้ามใส่กลับ), stack และงานที่ต้องทำต่อ
- `prototype.html` = ต้นแบบล่าสุดที่ผู้ใช้เล่นและอนุมัติแล้ว ใช้เป็นต้นแบบหน้าตา/แอนิเมชัน/ตรรกะวงล้อ
- `sheet-logger.gs` = Apps Script รับข้อมูลลง Google Sheet
- ภาษาหน้าเว็บ: ไทย · ผู้ใช้สื่อสารภาษาไทย
- มีคำถามค้างอยู่ 1 ข้อ (แลกของแบบเปิดเผยหรือลับ) ให้ถามผู้ใช้ก่อนทำหน้าจอเวทีกาชาปอง
