- ✅ ไม่มีโลโก้/ตัวละครของแบรนด์ในรูปอ้างอิง
- ⚠️ ไฟล์ต้นฉบับใหญ่เกินเป้า 300 KB ทุกไฟล์ → แปลงเป็น WebP + ย่อขนาดให้แล้ว (ไฟล์ใหญ่สุดในเว็บ ~108 KB)

## หมายเหตุ — สีมาสคอต
Prompt สั่ง "พริกแดง" แต่ได้ **ตัวกลมสีเขียว + ขั้วเขียว** (ดูเหมือนพริก/มะนาวลูกกลม หรือ "ลูกมัทฉะ")
ข้อดี: เขียวตัดกับพื้นแดงชัดมาก และเข้ากับ Matchazuki · ใช้ทุกภาพสม่ำเสมอ จึง **แนะนำให้ใช้ต่อ** ไม่ต้องสั่งใหม่
ถ้าอยากให้ตรงคอนเซ็ปต์ "จี๊ด = พริก" ให้ตัดสินก่อนเริ่มใส่ภาพลงหน้าเว็บ (เปลี่ยนทีหลังต้องทำใหม่ทั้งชุด)
