## Microcopy

| จุดที่ใช้ | ข้อความ 3 ตัวเลือก |
|---|---|
| ปุ่มเริ่มหมุนวงล้อ | ① หมุนเลย ลุ้นกัน<br>② ขอรางวัลเข้ามือ<br>③ เริ่มหมุน เริ่มเฮ |
| ปุ่มหยุดวงล้อ | ① หยุดเลย ตรงนี้แหละ<br>② พอแล้ว ลุ้นไม่ไหว<br>③ หยุดหมุน ได้ลุ้น |
| ข้อความตอนได้ของรางวัล | ① ยินดีด้วย! รางวัลนี้ของคุณ<br>② ได้ของแล้ว ได้เวลาเฮ!<br>③ ดวงมา รางวัลเข้า! |
| ปุ่มบันทึกแล้วหมุนต่อ | ① บันทึก แล้วหมุนต่อ<br>② เก็บผล ไปลุ้นต่อ<br>③ บันทึก แล้วลุยต่อ |
| หน้ารอเข้าห้องกาชาปอง | ① รอเข้าห้อง อีกนิดได้ลุ้น<br>② เตรียมใจไว้ แคปซูลกำลังมา<br>③ รอก่อนนะ ดวงกำลังตั้งตัว |
| ข้อความตอนแคปซูลแตก | ① เปิดแล้ว! มาดูกันได้อะไร<br>② แคปซูลเปิด ความลุ้นจบ!<br>③ แต่นแต๊น! ของใครกันนะ |
| ปุ่มโหวต | ① โหวตให้คนนี้<br>② เทคะแนนให้เลย<br>③ ลุคนี้ ขอเทใจ |
| ข้อความยืนยันโหวต (เตือนว่าแก้ไม่ได้) | ① ยืนยันโหวตให้คนนี้? ยืนยันแล้วแก้ไขไม่ได้<br>② เลือกคนนี้แน่นะ? ส่งคะแนนแล้วเปลี่ยนไม่ได้<br>③ พร้อมเทคะแนนไหม? ยืนยันแล้วเปลี่ยนใจไม่ได้ |
| ข้อความหลังโหวตแล้ว | ① รับคะแนนแล้ว ขอบคุณที่ร่วมโหวต!<br>② ส่งคะแนนเรียบร้อย รอลุ้นผลกัน<br>③ เทใจสำเร็จ เหลือแค่ลุ้น! |
| จอเวทีระหว่างรอผล | ① คะแนนกำลังรวม เสียงเชียร์พร้อมไหม?<br>② อีกนิดรู้ผล ซ้อมเฮรอเลย<br>③ ลุ้นได้ แต่อย่าเพิ่งกลั้นหายใจ |
| ประกาศผู้ชนะ | ① ผู้ชนะคือ… {ชื่อ} ขอเสียงปรบมือ!<br>② เวทีนี้ยกให้ {ชื่อ}!<br>③ มงลงแล้ว! ยินดีกับ {ชื่อ} |
| หน้า 404 | ① หน้านี้หลงทาง กลับไปเลือกเกมกัน<br>② หมุนเจอรางวัล แต่หาหน้านี้ไม่เจอ<br>③ จี๊ดหาไม่เจอ กลับหน้าหลักกันนะ |

`{ชื่อ}` = ตัวแปร ใส่ชื่อผู้ชนะตอนแสดงผล

## สคริปต์พิธีกร — จับฉลากของขวัญ (~1 นาที)

อิง flow ล่าสุด (PRODUCT.md D10: Lucky Number แทนลูกเต๋า) ถ้อยคำเรื่องการล็อกผลต้องตรงกับการทำงานจริงของระบบ
(สคริปต์ลูกเต๋าเดิมจาก ChatGPT เลิกใช้แล้ว 2026-11-18)

> ก่อนเปิดแคปซูล ขอเล่ากติกานิดหนึ่งนะครับ!
>
> ตอนเข้าห้อง ทุกคนหยิบการ์ด Lucky Number กันเองคนละใบ แล้วกรอกเลขคู่กับชื่อตัวเองในมือถือ ระบบจะเอา "ชื่อกับเลขของทุกคน" มาสุ่มครั้งเดียว ใครได้เลขไหน มาจากมือคุณเองล้วนๆ
>
> พูดง่าย ๆ คือ ระบบล็อกผลให้ใครล่วงหน้าไม่ได้ จะผู้บริหารหรือทีมงานก็ต้องลุ้นเหมือนกัน งานนี้ตำแหน่งช่วยไม่ได้ ต้องให้การ์ดช่วยครับ!
>
> ใครสงสัย ตรวจสอบเองได้เลย สแกน QR บนจอแล้วกดคำนวณ ได้ผลเดียวกันทุกครั้ง ถ้าตรงไหนไม่ชัด ทักทีมงานได้ทันทีครับ
>
> เอาล่ะ เช็กชื่อตัวเองบนจอว่าครบ เตรียมเสียงเชียร์ให้พร้อม จับได้ชื่อใคร ได้ของขวัญของคนนั้น… ไปลุ้นกันเลยครับ!
